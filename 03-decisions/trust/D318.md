**D318 (LOCKED Session 401)** — Blocking someone never costs the picker money and never files a strike, whatever the timing. Nick's ruling, 2026-08-10: the consented fee disclosure says a block releases the authorization with no exception, and the 2-hour grace window that governs a manual cancel does not apply to a block-initiated one — the terminal state is cancelled, never no_show, and no late_cancel trust event or strike is filed. A block that ends a live claim is still recorded — naming the blocker, the claim, and the fact that a live claim was ended — as a Report row on the existing auto-flag review surface, so a picker using block as a free cancel shows up as a pattern for review.
