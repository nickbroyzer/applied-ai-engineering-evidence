**D264 (LOCKED Session 376)** — Rule 2 (GPS spam) is retired and replaced by a location-free listing tempo guard. The old rule flagged any giver with 3+ listings within 100m in one hour and set the listing to `hidden_pending_review`, firing on exactly the behaviour the launch depends on: a mover clearing a house from one address. Two listings hidden by it had sat invisible for six and eleven weeks before being found and released this session. Replacement `check_rule_2_listing_tempo` triggers on either a second listing inside `MIN_LISTING_INTERVAL_SECONDS` (10) or more than `MAX_LISTINGS_PER_DAY` (50) in 24 hours, with no location component. 10 seconds sits far below human give-flow speed — Session 375's four legitimate listings averaged 22 seconds apart — while a script clears it instantly. Both values are module-level constants, so retuning is a one-line edit. CORRECTION to the PROPOSED text: the "enforce before the AI call" clause rested on a false premise — the create-listing path contains no AI call, since photo analysis happens earlier on a separate endpoint, so there was nothing to reorder. The three retired location tests in `test_scam_detection.py` were rewritten against the tempo guard; that file is 44 passed. Commit `8115ae6`, deployed.
