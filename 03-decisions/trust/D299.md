**D299 (LOCKED Session 387)** — Trust is earned per handoff on a symmetric signed scale, and every score carries a word. REPLACES canonical decision 2 (trust score 0–100 with New/Good/Great/Trusted labels) and SUPERSEDES D63 (New/Reliable at three completions) and the display half of D67. The old model set 0 with no completed transactions and jumped to 100 on the first, then only deducted — so the first handoff handed out a perfect score and the ring never moved again. Now: a completed transaction is a flat POINTS_PER_COMPLETION, the same award eco already gives, so a full ring takes many handoffs and is meant to be rare. Deductions were scaled by a constant factor to keep D67's proportions across `late_cancel`, `no_show` and dispute-lost for either role; **tuned constants withheld**. The first-infraction grace survives but now applies to the oldest UNHEALED infraction rather than the oldest infraction ever, so grace resets after healing. HEAL_THRESHOLD clean completions still heal an infraction: healing removes its deduction and returns it to the free-infraction pool, but never returns points — points come only from handoffs, which is what "earned" means. The score runs across a symmetric signed range with no floor at zero, so an account that has done more harm than good is visibly distinct from one that has done nothing yet; a migration widened the users.trust_score check constraint accordingly, and a rollback would need out-of-range rows clamped before the downgrade can recreate the old constraint. Display: both rings fill toward the ceiling and print the real score, and the trust ring's TRACK turns red below zero, since an arc at a negative value has nothing to draw. Each ring also carries a one-word descriptor computed from the history behind the number, not the number alone, because a low score cannot otherwise distinguish a new account from a damaged one — trust reads Poor below zero, New at no completions, Mixed whenever any infraction exists, then Getting started / Solid / Excellent by completion count; eco reads New / Getting started / Contributor / Champion / Hero by score, all positive, since eco has no infractions and cannot go negative. trust_label and compute_trust_level are deleted. trust_descriptor survives in code but is now dead and is filed for deletion in the backlog.
