**D225 (LOCKED Session 338, filed Session 339):** The message interceptor is universal enforcement at the single message-send choke point, extending the EXISTING `scam_detection` engine rather than a parallel module. Tier-1 (hard block): phone / phone-request / email / handle / link / off-platform-payment / scheduling. Tier-2 (silent-and-logged): address / cancel / confirm, surfaced as chips only where a built destination exists for that chip to route to. Rationale: a parallel content-check module would duplicate the block path and response shape; one choke point keeps enforcement consistent across every message send.
