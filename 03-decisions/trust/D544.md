D544 — LOCKED (2026-09-26, Nick's rulings, Session 465). REFERRAL CREDIT RULES (D539 STEP 5, AMENDS D540). (1) The referrer earns 1 credit on the friend's first qualifying donation. A donation picked up by the referrer never qualifies and does not use up the friend; the friend's next donation to someone else qualifies. (2) No credit when any card the friend has used matches any card the referrer has used, or when the referrer's card paid for that donation's pickup; either case raises a Control Center alert. (3) One iPhone counts as only one referred friend. Claude's default: checked with DeviceCheck when a code is entered; a second account on an iPhone already used by a referred friend is still attributed but never earns the referrer a credit, and Control Center is alerted. (4) A friend's personal code wins over an Android Play-referrer campaign stamp. (5) Defaults set from filed rules: only donations completed after the friend entered the code count; up to 5 referral credits per referrer, lifetime; only personal codes earn; a deleted referrer earns nothing and a friend who deletes and re-signs up cannot be referred twice; everything is hidden while the referrals switch is off; codes are ZB- plus 6 characters without look-alikes (built in 1fd36d6).
