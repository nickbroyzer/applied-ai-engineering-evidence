**D18 — Structured-only listing flow with A/B AI choice** *(Session 88 + Session 89)*
The listing flow is fully structured. No free-text listing input. Photo capture → AI readability gate (retake if unreadable) → AI generates Option A (specific) + Option B (generic), both shown with a visual confidence indicator → giver picks one, locks instantly → giver picks deadline (today / this week / no rush / specific date+time) → publish.

No add-on fields (brand, model, size, color). No damage checkboxes. No edit path. Delete-and-restart is the only correction.

Confidence indicator format is a design-phase decision (visual, intuitive, non-clinical — no percentages, no clinical band labels).

Stale-listing policy is two-stage, config-flag cutover:
- Steady-state: deadline passes → listing pauses → "still available?" notification → no reply → second notification → auto-removed.
- Early-launch (Capitol Hill bootstrap): deadline passes → listing stays visible with "past deadline" indicator → before claim, system pings giver → giver confirms → only then picker can claim and pay $2 → no confirmation → claim blocked → same two-notification removal.

**Status: OPEN. Implementation is Phase 7+ work. Does NOT block Phase 6 STEP 2.**
