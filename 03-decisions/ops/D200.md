**D200 — Daily-job scheduling via single runner** *(Session 313, 2026-06-29)*
Decision: All four digest-lane jobs (recommendations, saved-deadline reminders, listing-expiry nudges, pickup reminders) are consolidated into a single Railway cron service (`robust-success`) running `python -m app.jobs.run_daily_jobs` at 15:00 UTC daily. The runner calls each job with `digest=True` so jobs write inbox rows only (no per-event push). After all four jobs complete, the runner calls `send_daily_digest_summaries` to send one summary push per user who has new digest-lane inbox rows today. `run_saved_deadline_scan.py` is retired as the cron entrypoint.

Rationale: A single entrypoint is simpler to monitor, avoids overlapping cron schedules, and ensures `send_daily_digest_summaries` fires after all digest jobs have populated their inbox rows.

Scope: `backend/app/jobs/run_daily_jobs.py` (new runner); Railway cron `robust-success` Custom Start Command updated to `python -m app.jobs.run_daily_jobs`, root dir `backend`, schedule `0 15 * * *` UTC. Deploy confirmed Session 313.
